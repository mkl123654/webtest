## 一、项目概述

胖喵是一个内容推荐平台，按"类型/城市/场景"等多维度标签组织美食、旅游、娱乐等推荐内容。用户可浏览、搜索、收藏、评论、评分，AI 助手（胖喵数字分身）提供对话式推荐。

**三层架构：**

```
web (:3000) ─── Next.js 15 ───┐
admin (:3005) ── Next.js 15 ──┼── NestJS 11 (:4000) ── MySQL 8.1
                               │
                               └── DeepSeek API（AI 对话）
```

## 三、数据模型

```prisma
model User {
  id        Int       @id @default(autoincrement())
  username  String    @unique @db.VarChar(50)
  password  String    @db.VarChar(255)
  role      String    @default("USER") @db.VarChar(10)
  avatar    String    @default("🐱") @db.VarChar(10)
  bio       String    @default("") @db.VarChar(200)
  comments  Comment[]
  ratings   Rating[]
  favorites Favorite[]
}

model Post {
  id          Int       @id @default(autoincrement())
  title       String    @db.VarChar(50)
  description String    @db.VarChar(200)
  emoji       String    @db.VarChar(10)
  badge       String    @db.VarChar(10)
  content     String?   @db.Text
  images      String?   @db.Text
  published   Boolean   @default(false)
  sortOrder   Int       @default(0)
  ratingAvg   Float     @default(0)
  ratingCount Int       @default(0)
  comments    Comment[]
  ratings     Rating[]
  favorites   Favorite[]
  categories  PostCategory[]
}

model CategoryGroup {
  id         Int        @id @default(autoincrement())
  key        String     @unique @db.VarChar(20)
  label      String     @db.VarChar(20)
  sortOrder  Int        @default(0)
  categories Category[]
}

model Category {
  id        Int            @id @default(autoincrement())
  key       String         @unique @db.VarChar(20)
  label     String         @db.VarChar(20)
  icon      String         @db.VarChar(10)
  sortOrder Int            @default(0)
  groupId   Int
  group     CategoryGroup  @relation(fields: [groupId], references: [id], onDelete: Cascade)
  posts     PostCategory[]
}

model PostCategory {
  postId     Int
  categoryId Int
  post       Post     @relation(fields: [postId], references: [id], onDelete: Cascade)
  category   Category @relation(fields: [categoryId], references: [id], onDelete: Cascade)
  @@id([postId, categoryId])
}

model Comment {
  id        Int       @id @default(autoincrement())
  content   String    @db.Text
  postId    Int
  userId    Int
  parentId  Int?
  parent    Comment?  @relation("CommentReplies", fields: [parentId], references: [id], onDelete: Cascade)
  replies   Comment[] @relation("CommentReplies")
  user      User      @relation(fields: [userId], references: [id], onDelete: Cascade)
  post      Post      @relation(fields: [postId], references: [id], onDelete: Cascade)
}

model Rating {
  id     Int  @id @default(autoincrement())
  score  Int
  postId Int
  userId Int
  post   Post @relation(fields: [postId], references: [id], onDelete: Cascade)
  user   User @relation(fields: [userId], references: [id], onDelete: Cascade)
  @@unique([postId, userId])
}

model Favorite {
  id     Int  @id @default(autoincrement())
  userId Int
  postId Int
  user   User @relation(fields: [userId], references: [id], onDelete: Cascade)
  post   Post @relation(fields: [postId], references: [id], onDelete: Cascade)
  @@unique([userId, postId])
  @@index([userId])
}
```

## 四、API 接口

基路径：`/api`

### 4.1 认证

| 方法 | 路径 | Auth | 说明 |
|------|------|------|------|
| POST | `/auth/register` | — | 注册 `{ username, password }` |
| POST | `/auth/login` | — | 登录，返回 JWT |

### 4.2 用户

| 方法 | 路径 | Auth | 说明 |
|------|------|------|------|
| GET | `/users/me` | JWT | 获取当前用户信息 |
| PUT | `/users/me` | JWT | 更新资料 `{ username, avatar, bio }` |
| PUT | `/users/me/password` | JWT | 修改密码 |

### 4.3 帖子

| 方法 | 路径 | Auth | 说明 |
|------|------|------|------|
| GET | `/posts?category=` | — | 已发布帖子列表，`category` 逗号分隔多标签 |
| GET | `/posts/:id` | — | 帖子详情（含评论树） |
| GET | `/search?q=&category=` | — | 全局搜索 |
| GET | `/categories` | — | 标签分组及标签列表 |
| POST | `/posts/:id/comments` | JWT | 发表评论 `{ content, parentId? }` |
| GET | `/posts/:id/comments` | — | 获取评论 |
| POST | `/posts/:id/rate` | JWT | 评分 `{ score: 1-5 }` |
| GET | `/posts/:id/rating` | JWT | 获取当前用户评分 |

### 4.4 收藏

| 方法 | 路径 | Auth | 说明 |
|------|------|------|------|
| GET | `/favorites?category=` | JWT | 收藏列表 |
| POST | `/favorites` | JWT | 添加 `{ postId }` |
| DELETE | `/favorites?postId=` | JWT | 取消收藏 |
| GET | `/favorites/check?postIds=` | JWT | 批量检查收藏状态 |

### 4.5 管理端（需 Admin 角色）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET/POST/PUT/DELETE | `/admin/posts` | 帖子 CRUD，`categoryIds` 多标签 |
| PATCH | `/admin/posts/:id/toggle` | 切换发布状态 |
| GET | `/admin/stats` | 统计概览 |
| POST | `/admin/upload` | 图片上传 |
| GET/POST/PUT/DELETE | `/admin/category-groups` | 标签分组管理 |
| GET/POST/PUT/DELETE | `/admin/categories` | 标签管理 |
| GET/POST/PUT/DELETE | `/admin/users` | 用户管理 |

### 4.6 AI 对话

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/chat` | DeepSeek 流式对话（SSE） |

├── layout.tsx                    ← 根布局（AuthProvider）

│   │   └── FavoritesContent.tsx
│   └── settings/
│       └── page.tsx              ← 个人设置
├── post/
│   └── [id]/
│       └── page.tsx              ← 帖子详情
├── login/page.tsx

URL 约定：
- `/?categories=food` — 标签筛选
- `/favorites?category=food` — 收藏筛选
- `/post/123` — 帖子详情

## 六、交互规范

### 6.1 移动端 ≤768px

| 元素 | 行为 |
|------|------|
| ☰ 汉堡按钮 | 45px 圆形，`left:0`，4s 闲置后左缩 22px + opacity:0.5，hover/touch 展开 |
| 😼 ChatFloat | 45px 圆形，同上缩回逻辑，左右侧吸附后向对应方向缩 |
| 搜索栏 | `scale(0.90)`，左 padding 45px 贴齐汉堡 |
| 底部 TabBar | 60px 高，3 列网格（推荐/收藏/设置） |
| 左侧菜单 | 290px 滑出抽屉 + 遮罩 |
| 设置页 | 双栏 → 单栏堆叠 |

### 6.2 ChatFloat 拖拽

- 触发：mousedown/touchstart → mousemove/touchmove → mouseup/touchend
- 5px 阈值区分点击与拖拽
- 左右 30px 内自动吸附
- 位置存入 `localStorage`（key: `chat-float-pos`）
- PC 长条 pill 形态，移动端 45px 圆形

### 6.3 收藏按钮

- 卡片右上角心形图标 ♡/❤️
- 点击切换，`e.stopPropagation()` 阻止卡片跳转
- `.pop` 弹跳动画（cubic-bezier）

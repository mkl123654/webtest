# Changelog

## V1.0.0 (2026-06-09)

### 架构

三层分离部署：

| 层 | 技术栈 | 端口 |
|----|--------|------|
| 🖥️ Web 前端 | Next.js 15 App Router | 3000 |
| 🛠️ Admin 后台 | Next.js 15 | 3005 |
| ⚙️ API 后端 | NestJS 11 + Prisma 6 + MySQL 8.1 | 4000 |

### 功能清单

#### 用户系统
- JWT 注册/登录
- 个人资料编辑（头像/用户名/介绍）
- 密码修改

#### 推荐内容
- 多维度标签系统：23 个标签，3 个分组（类型/城市/场景）
- 标签动态渲染，新增标签零前端改动
- 多标签筛选：`?categories=food,shenzhen`
- 全局搜索（支持标签过滤）
- 帖子详情页 `/post/[id]`，含评分、评论

#### 收藏
- 收藏/取消收藏（心形按钮 + 弹跳动画）
- 收藏列表，按标签筛选
- 批量检查收藏状态

#### AI 助手（ChatFloat）
- DeepSeek 流式对话
- 快捷提问芯片（吃啥/喝啥/去哪玩/找乐子）
- 拖拽移动（PC + 移动端）
- 左右边缘吸附（30px 阈值）
- 位置 localStorage 记忆
- 自动缩回：4s 闲置后半隐藏 + 半透明，hover/touch 展开
- 移动端圆形按钮 45px

#### 移动端适配
- ≤768px 响应式布局
- 汉堡菜单 + 侧滑抽屉
- 底部 TabBar（推荐/收藏/设置）
- 搜索栏 90% 缩放
- Tab 标签横向滑动
- 设置页双栏→单栏堆叠

#### 管理后台
- 仪表盘（统计概览）
- 内容管理：卡片 CRUD、发布/审核、多标签选择、图片上传
- 标签管理：分组 CRUD + 标签 CRUD（含图标选择器）
- 用户管理

### 数据库

| 表 | 用途 |
|----|------|
| User | 用户 |
| Post | 内容卡片 |
| CategoryGroup | 标签分组（类型/城市/场景…） |
| Category | 具体标签（美食/深圳/约会…） |
| PostCategory | 帖子↔标签多对多 |
| Comment | 评论（含嵌套回复） |
| Rating | 评分（1-5星） |
| Favorite | 收藏 |
